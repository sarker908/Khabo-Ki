Mapbox coverage check

A temporary developer page. It tests whether Mapbox can find restaurants in Bangladesh before the Restaurant Finder is migrated. Delete it when you no longer need it.

This sends about 15 requests to Mapbox, only when you press the button. It uses the public token in js/mapbox-config.js. A USA search is included as a control: if the control works but the Dhaka searches return nothing, Mapbox does not cover Bangladesh for restaurants.

Press the button to start.
